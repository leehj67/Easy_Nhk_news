# NHK Easy Reader

형주용 일본어 학습 프로그램 초안입니다.

## 기능
- NHK Easy News에서 기사 목록 불러오기
- 기사 1개 선택 후 문장 단위 읽기
- 각 문장별 핵심 단어 추출
- 단어 뜻/문장 해석 표시
- `기억하기` 버튼으로 단어 저장
- 같은 단어가 다른 기사에서 다시 나오면 관련 예문 누적
- 저장된 단어의 예문/기사 링크 추적

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 현재 버전 한계
- 형태소 분석기를 쓰지 않아 단어 추출은 정규식 기반의 간단한 방식입니다.
- 번역/해석은 `translate_text()` 스텁 함수로 되어 있어 실제 LLM API로 바꿔야 자연스러워집니다.
- NHK Easy 페이지 구조가 바뀌면 셀렉터 수정이 필요할 수 있습니다.
